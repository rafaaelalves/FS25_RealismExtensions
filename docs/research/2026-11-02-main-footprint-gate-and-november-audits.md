# RE Terrain SHADOW — coarse MAIN footprint screening and November source-audit crosswalk

**Date:** 2026-11-02. **Scope:** feature code and pure-Lua tests, **NOT physical terrain release**. Experimental branch PR #64 only; production RE/RC `main` unchanged. Previous source/evidence basis: `2026-10-31-terrain-quantized-fine-channel-handoff.md`, October 27 ADDITIVE 1.5 mm → 7.78 mm, October 29 absolute 1.5 mm → 3.891 mm (one MAIN vertex), and issue #63. This is an incremental **no-write SHADOW study**, not an invitation for additional gameplay tests.

## Code delivered

- `TerrainMainFootprintGate.lua` compares an **oriented wheel contact rectangle** (real `FootprintModel` width/length and per-contact direction) with the **square support cell** of the snapped coarse MAIN heightmap vertex. The intersection area is computed by clipping the rectangle against the four native-cell boundaries, not by an axis-aligned bounding box. The default provisional screening thresholds are support width/length each at least `0.75*mainUnit`, and overlapping native cell-area fraction at least `0.75`. **These are conservative research filters, not soil constants or validated physical writer thresholds.**
- Verdicts: `GEOMETRY_UNKNOWN` (unavailable ground contact, crawler geometry, stationary/undefined travel direction, invalid dimensions), `FINE_ONLY_OR_UNREPRESENTABLE` (narrow contact/seam/insufficient coverage), or `MAIN_RESEARCH_CANDIDATE` (passes the two-dimensional screen, **but no main write authorized**). Every output sets `authorizesMainWrite=false`.
- `TerrainAbsoluteHeightPlanner:observe` now accepts optional contact evidence from `TerrainDeformationEngine.processSample` and reports `mainGeometryState/mainGeometryReason/mainCellCoverage01` alongside quantum/demand. Counters distinguish fine-only, unknown and research candidates, keeping the actual demand/heightmap/persisted history separate. The old no-input harness works fail-closed (`GEOMETRY_UNKNOWN`).
- `modDesc.xml` loads gate before the planner. Unit and demand remain whatever existing journal/SHADOW provided. `TerrainPermanentActuator="SHADOW"` still blocks **all automatic RE native terrain writes**, and no tire-physics or native API call is introduced by the screening.
- Harnesses cover square, rotated and scaled direction, grid seam, missing orientation, narrow tyre, two narrow parallel tracks, crawler, unit 0.5 m, no-ownership, and separate SHADOW quantum vs coverage. Passing two thin 0.20m sources near one 1m vertex never implies an invented 1m-wide tire footprint.

## Crucial limitations

1. The current screen covers **one instantaneous contact footprint**, not an accurately reconstructed swept track path. It must not sum areas from independent samples or add 25 logical 0.20m source widths merely because they alias to one 1m vertex. Segment-union footprint provenance would be a separate carefully justified model.
2. `FootprintModel` may return low-confidence width/length estimates and excludes crawler groups; do not upgrade confidence automatically. A contact rectangle is not proof that a GIANTS heightmap vertex carries the same collision/deformation geometry as the native 0.125m wheel-surface.
3. The origin/grid offset used by `Planner.snap` is not fully verified map-by-map, and a high cell coverage does not validate curvature, local native vertical quantum, fine-channel synchronization, map ownership or soil-material balance. **A research candidate is not a write permit.**
4. The verdict is diagnostic/volatile. Future recovery must use proven journal-owned native heights and actually performed GIANTS tillage, not `SHADOW` demand or this gate's area-only verdict. Existing save's legacy rut cells do not gain fake geometric first-touch ownership.
5. Default threshold 75% is an intentionally strict preliminary choice. It can reject legitimate narrow tracks; this is safer than a coarse permanent cut and does not disable GIANTS native tire deformation or Mud sink.
